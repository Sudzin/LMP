# ТЗ: Локальный медиаплеер (рабочее название: Aurora Player)

## 1. Общее

- **Продукт:** десктопный медиаплеер для локальных аудио- и видеофайлов.
- **Платформа:** Windows 10/11, 64-bit.
- **Дистрибуция:** portable — один .exe (PyInstaller `--onefile --windowed`), без установки.
- **Сеть:** приложение полностью офлайн, без телеметрии и обращений в интернет.
- **Язык интерфейса:** RU/EN (переключаемо в настройках, по умолчанию RU).

## 2. Стек

| Слой | Технология |
|---|---|
| Язык | Python 3.12 |
| UI | PySide6 (Qt 6.7+), интерфейс на QML/Qt Quick |
| Воспроизведение | Qt Multimedia (QMediaPlayer + QAudioOutput, видео — Media Foundation) |
| Медиатека | SQLite (stdlib `sqlite3`) |
| Теги и обложки | mutagen |
| Эквалайзер | 10-полосный IIR (biquad), scipy.signal |
| Визуализатор | QAudioBufferOutput (Qt 6.7+) → FFT-спектр |
| Сборка | PyInstaller (`--onefile --windowed --icon app.ico`) |

## 3. Функциональные требования

### 3.1 Медиатека
- Рекурсивное сканирование выбранных папок (настройка папок источников).
- База SQLite: треки, альбомы, исполнители, жанры, плейлисты, история прослушивания.
- Чтение метаданных из тегов (ID3v2, Vorbis, MP4): название, исполнитель, альбом, жанр, номер трека, год, обложка.
- Обложки: из тегов, fallback — `cover.jpg`/`folder.jpg` в папке, fallback — сгенерированный плейсхолдер.
- Экраны: Главная (недавно добавленные, недавно проигранные, избранное), Исполнители, Альбомы, Жанры, Плейлисты, Очередь.
- Поиск по всем полям (мгновенный, при вводе). Сортировки: по названию, исполнителю, альбому, длительности, дате добавления.
- Отметка «избранное» (сердечко) на треке/альбоме/плейлисте.

### 3.2 Воспроизведение
- Аудио: mp3, flac, wav, ogg, m4a, aac.
- Видео: mp4, mkv, avi, mov (через системные кодеки Windows; для редких кодеков — понятное сообщение об ошибке).
- Плейлисты: создание, переименование, сохранение в БД; drag-and-drop треков.
- Очередь: «играть дальше», «добавить в очередь», «играть далее» из контекстного меню; очередь редактируема.
- Режимы: повтор (выкл / трек / плейлист), shuffle.
- Сохранение позиции: при перезапуске приложение предлагает продолжить с места остановки.

### 3.3 Видео и субтитры
- Внешние субтитры: `.srt`, `.ass`, `.vtt` — автопоиск файла рядом с видео (совпадение имени), выбор дорожки вручную, позиционирование/размер в настройках.
- Встроенные субтитры из контейнера: если Qt Multimedia не отдаёт — честное сообщение «не поддерживается», без падений.
- Полноэкранный режим с автоскрытием панели управления.

### 3.4 Звук
- Эквалайзер: 10 полос (31, 62, 125, 250, 500, 1k, 2k, 4k, 8k, 16k Гц), диапазон ±12 дБ.
- Пресеты: Flat, Рок, Поп, Джаз, Электронная, Бас-буст, Кастомный (сохранение).
- Скорость воспроизведения: 0.5x–2.0x (шаг 0.1).
- Таймер сна: через N минут / в конце трека — пауза или выход.

### 3.5 Управление
- Глобальные мультимедиа-клавиши (play/pause, next, prev) — работают при свёрнутом окне.
- В окне: `Пробел` — play/pause; `↑`/`↓` — громкость ±5%; `←`/`→` — перемотка ∓10 сек (с зажатым Shift ∓5 сек); `M` — mute; `F` — полный экран; `Esc` — выход из полного экрана.

## 4. Дизайн

- Референс: Spotify. Тёмная тема, крупные карточки, левая навигационная панель, нижний полноширинный блок «сейчас играет».
- **Фон главного экрана:** размытие (blur) по цветам обложки текущего трека, как у Spotify; цвета плавно перетекают при смене трека.
- **Акценты:** градиенты (пурпурно-розовые, оранжево-красные, лаванда). Доминирующие зелёный и синий — избегать.
- **Темы:** минимум 3 встроенные (классическая тёмная + 2 градиентные) + выбор кастомного акцентного градиента. Переключение без перезапуска.
- **Анимации:** визуализатор спектра в «сейчас играет» (вкл/выкл в настройках), плавные переходы между экранами (300–400 мс, easing curves), hover-эффекты на карточках (подъём + масштаб + подсветка), particles-фон на главной (умеренно, 30–50 частиц, отключается в настройках), пульсация кнопки play в такт (опционально).
- UI на QML: все переходы через `Transition`/`Behavior`, анимации не блокируют интерфейс.

## 5. Архитектура

```
player/
├── main.py              # точка входа, QApplication, engine setup
├── backend/
│   ├── player_controller.py  # QMediaPlayer-обёртка, состояние, эквалайзер
│   ├── library_db.py         # SQLite: схема, запросы
│   ├── tag_reader.py         # mutagen: метаданные + обложки
│   ├── playlist_manager.py
│   ├── subtitles.py          # парсеры srt/ass/vtt
│   ├── hotkeys.py            # глобальные клавиши (RegisterHotKey через ctypes/pyWinhook)
│   └── settings.py           # QSettings
├── ui/
│   ├── qml/                  # Main.qml, экраны, компоненты, темы
│   └── resources.qrc         # шрифты, иконки, шейдеры
├── assets/                   # app.ico, плейсхолдеры обложек
└── build.spec                # PyInstaller spec
```

Правила: backend не импортирует QML; общение через сигналы/слоты и контекстные свойства. Никаких абсолютных путей — только `resource_path()`-утилита и `%APPDATA%/AuroraPlayer` для БД и настроек.

## 6. Сборка в exe

- `build.spec`: `--onefile --windowed --name AuroraPlayer --icon assets/app.ico`.
- Все ресурсы через `.qrc`; временные файлы БД/кэша — в `%APPDATA%`, рядом с exe ничего не пишем.
- Целевая машина: чистая Win10/11 без Python. Проверка после сборки на VM.

## 7. Этапы (по одному за раз, каждый — рабочая версия)

**MVP (фаза 1):**
1. Каркас: окно, навигация, нижний блок «сейчас играет».
2. Воспроизведение аудио/видео: open file, плей/пауза, seek, громкость, видео-область.
3. Горячие клавиши в окне.
4. PyInstaller-сборка в exe, проверка на чистой системе.

**Фаза 2:** медиатека (сканирование, SQLite, экраны, поиск), плейлисты и очередь, субтитры.

**Фаза 3:** эквалайзер + пресеты, визуализатор спектра, анимации/темы/particles, глобальные клавиши, RU/EN, иконка и имя.

## 8. Критерии приёмки MVP

- Открывает и проигрывает mp3/flac и mp4, seek и громкость работают.
- Пробел/стрелки работают в окне.
- `AuroraPlayer.exe` запускается на Windows без Python и играет файл с рабочего стола.
