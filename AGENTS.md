# AGENTS.md — Aurora Player

## Проект
Локальный медиаплеер (аудио + видео) для Windows 10/11. Portable exe. Полностью офлайн.
Полное ТЗ — в `SPEC.md`, читай его перед каждой задачей.

## Стек (фиксирован)
Python 3.12 · PySide6 (Qt 6.7+) · QML/Qt Quick UI · SQLite · mutagen · scipy · PyInstaller.
Новые зависимости — только после согласования с владельцем проекта. Не используй Electron/web-стек.

## Команды
- Запуск: `python main.py`
- Проверка QML/логики: запуск + ручной сценарий из `SPEC.md §8`
- Сборка exe: `pyinstaller build.spec` (или `pyinstaller --onefile --windowed --icon assets/app.ico main.py`)

## Железные правила
1. Комментарии и docstring — на русском, имена — английские.
2. Никаких абсолютных путей. Ресурсы — через `resource_path()` и `.qrc`; данные пользователя — `%APPDATA%/AuroraPlayer`.
3. Все длительные операции (сканирование библиотеки) — в отдельных потоках (QThread), UI не блокируется.
4. Анимации — только QML `Behavior`/`Transition`, без таймеров в Python для UI.
5. Доминирующие зелёный и синий в UI не использовать; акценты — градиенты (см. `SPEC.md §4`).
6. Каждая фаза из `SPEC.md §7` заканчивается рабочей версией — не ломать уже работающее.
7. Перед изменением архитектуры — предложи план и дождись подтверждения.
